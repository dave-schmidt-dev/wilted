Manual playlists and automatic playlists are sidebar entries. Add to playlist lives in the item's context menu and multi-select. Up Next stays the playback queue.

Data contract
  • Collection: id, kind manual|automatic, name; stable IDs, rename and delete never touch items.
  • Manual: ordered [ItemID] membership. Automatic: Rule over feed, media kind, downloaded or prepared, unplayed, date, duration. Evaluated deterministically from domain state, never from the current view.
  • Up Next is not a collection. Multi-select assignment is one action over many IDs.

Option B: Categories as labels and filter chips

Items and feeds carry labels. The Menu shows label chips as filters; an automatic category is a saved rule shown as a chip.

Data contract
  • Same Rule evaluator as A; membership is many-to-many (ItemID, Label) with no order.
  • Trade-off: no manual ordering, so a hand-built sequence is not possible. Categories also tag feeds, so new episodes inherit labels.
  • Cost: no new sidebar destinations; filters share the Menu's sort.
